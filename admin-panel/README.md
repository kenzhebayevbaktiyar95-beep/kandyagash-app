# Qandyagash Admin Panel

This is a lightweight admin dashboard starter for the Qandyagash Life platform.

## Features

- Overview summary
- Revenue by payment provider
- Recent orders feed
- Services activity status

## Quick start

```bash
cd admin-panel
npm install
npm run dev
```

Then open:

```text
http://localhost:5000/api/dashboard
```

## Future improvements

- Authentication for admin users
- Dashboard UI using React or Next.js
- Real-time order update integration
- Export to CSV / Excel
- Webhooks from payment provider and backend
- Role-based access control

This is a starter for MVP management of city services, payment stats, and operations.
